# ECOUNT ERP 货柜费用分摊与导入表生成工具

自动化处理货柜清关费用分摊、新品目编码生成、采购入库及 ECOUNT 会计凭证批量导入表格的 Python 工具。

## 核心功能

1. **货柜费用分摊核算**：
   - 包含货柜清关三费（进口清关杂费、国内海运运费、清关代理费）的自动分摊与核算。
   - 支持**固定分摊**与**浮动分摊**两种业务模式。
2. **全套 ECOUNT 导入表自动生成**：
   - **一般凭证上传格式**（13列）：清关杂费分摊会计凭证自动平账生成。
   - **采购入库格式**（25列）：按货柜及品目明细汇总并生成采购入库单。
   - **新品目格式**（17列）：自动提取未录入品目并规范编码生成新品目上传表。
   - **品目编码主数据**（11列）：品目编码维护与更新表。
   - **货柜三费分摊明细表**（14列）：费用分摊明细核对表。
3. **可视化交互界面 (GUI)**：
   - 基于 Tkinter 构建直观友好的图形界面 (`container_gui.py`)。
   - 支持动态列映射配置与位置调整。
   - 内置往来单位编码映射与品目主数据管理。
   - 实时日志输出与运行状态反馈。

## 项目结构

```text

├── requirements.txt      # 依赖包列表
├── .gitignore            # Git 忽略文件（已过滤 Excel 及可执行文件）
└── README.md             # 项目说明文档
```

## 环境依赖与运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行 GUI 界面

```bash
python container_gui.py
```

### 3. 命令行运行

```bash
python process_container.py <发货记录Excel路径>
```
